## Commands

Run from the project root:

```sh
python3 harness/sample.py --bench minif2f --n 60 --seed 20261013 --out problems/main_minif2f.txt
python3 harness/sample.py --bench minif2f --n 10 --seed 20261013 --out problems/pilot_minif2f.txt
python3 harness/sample.py --bench putnam  --n 60 --seed 20261013 --out problems/main_putnam.txt
python3 harness/sample.py --bench putnam  --n 10 --seed 20261013 --out problems/pilot_putnam.txt
```

## Method

- Eligibility. miniF2F: `OK` row in `data/minif2f_check.tsv` and exactly one `sorry` in the file. Putnam: file in `data/putnam_subst/` with exactly one `sorry`. All 244 miniF2F and all 672 Putnam files are eligible.
- Strata. miniF2F: name prefix before the first `_`; `mathd_algebra` and `mathd_numbertheory` are separate. Putnam: decade x answer flag; "answer" means the file defines `<name>_solution`.
- Sampling. `random.Random(seed)` shuffles each stratum. The Webster (Sainte-Lague) divisor method then gives slots to strata one at a time; each slot takes the next problem of that stratum. The sample of size n is the first n slots. A divisor method is house-monotone, so for one seed each pilot set is a subset of its main set. Same arguments give the same output.
